# v0.1.6

Google 账号分别建立独立网关连接，适配 codex-proxy-rs 3.41.2 / Windows x64。

- 每个 Google 账号有独立上游、连接密钥与用量统计；引擎通过唯一模型前缀固定选号
- 每行提供“重新授权”“同步连接”“删除”，重新授权沿用账号连接 ID；删除先停用连接并移除本机授权
- 授权失效与额度、速率限制分别显示，防止把额度限制当作需要重新登录
- 重复同步保留名称、手动启停、并发、权重和额外分组
- 旧合并上游在全部同步后停用并保留历史，旧用量不追溯拆分

发行包包含本机引擎与依赖，使用时无需编译。插件 ID 保持 `local.gemini-bridge`。升级后执行一次“同步全部账号并连接”；新增独立连接端口默认为中转端口加 1，可在设置中调整。

本版通过 10 项 Rust 测试、严格 Clippy、Vue 构建、20 项隔离宿主检查和 6 项实际引擎本机路由检查。本版未登录真实 Google 账号或生成媒体；真实 Gemini 及网关 Responses 的历史验证基线为 0.1.4，完整范围见 docs/VERIFICATION.md。
